# PokéDestino

Randomlocke de Kanto por escenas, para jugar con amigos en el navegador.

Juego de fans sin ánimo de lucro. Pokémon y sus personajes son propiedad de Nintendo, Game Freak y The Pokémon Company; los gráficos y mapas proceden de Pokémon Añil. Las partidas se guardan en el navegador de cada jugador.
